# CAPA-001 · План коригувальних і попереджувальних дій (INC-001 / PM-001)

**Коригувальна дія (Corrective)** усуває причину **вже виниклого** збою, щоб саме він не повторився.
**Попереджувальна дія (Preventive)** усуває причину **потенційного** збою, який RCA виявив, але який ще не стався.
Головне поле кожної картки — **перевірка ефективності**: як і коли доведено, що дія працює.
